# Barcode Studio

تطبيق سطح مكتب بسيط لإنشاء باركودات Code 128 ورموز QR، مع دعم العربية والإنجليزية والفرنسية، الوضع الليلي، المعاينة، الحفظ كصورة، والطباعة عبر طابعات Windows.

## التشغيل والتطوير

```bash
npm install
npm run dev
```

## إنشاء نسخة Windows

```bash
npm run dist
```

ينتج الأمر مثبت NSIS ونسخة محمولة داخل مجلد `release`. التطبيق متوافق مع Windows 10 وWindows 11 (x64).
