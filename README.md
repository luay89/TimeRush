# Barcode Studio

تطبيق سطح مكتب لإنشاء باركودات Code 128 ورموز QR، مع دعم العربية والإنجليزية والفرنسية، الوضع الليلي، المعاينة، الحفظ كصورة، والطباعة عبر Windows.

## وظائف الإصدار 0.2

- إضافة اسم المنتج والسعر والعملة، مع تحديد مكان وحجم بيانات المنتج.
- معايرة الطباعة: الهامش العلوي، الهامش الجانبي، المسافة بين الملصقات، ومقياس الطباعة.
- تحديد عدد النسخ المطلوب طباعتها مباشرة من إعدادات الطباعة.
- سجل آخر الباركودات مع البحث، التعديل، إعادة الطباعة، والحذف، محفوظ محليًا.
- إنشاء Code 128 بالأرقام أو بدون أرقام، وإنشاء QR Code.

## التشغيل والتطوير

```bash
npm install
npm run dev
```

## إنشاء نسخة Windows

```bash
npm run dist
```

ينتج الأمر مثبت NSIS ونسخة محمولة داخل مجلد `release`. التطبيق مخصص لـ Windows 10 وWindows 11 بنظام x64.
