# Barcode Studio

تطبيق سطح مكتب لإنشاء باركودات Code 128 ورموز QR مع دعم العربية والإنجليزية والفرنسية، الوضع الليلي، المعاينة، الحفظ والطباعة عبر Windows.

## الإصدار 0.3

- مسح الباركود وQR باستخدام كاميرا الجهاز في نسخة Windows.
- تحديث المعاينة تلقائيًا عند تغيير نوع الباركود أو النص أو بيانات المنتج.
- إدخال نتيجة المسح مباشرة في حقل الباركود وإعادة إنشاء المعاينة.
- تحديد عدد النسخ للطباعة.
- نسخة Android مستقلة مبنية على Expo SDK 54، تدعم كاميرا الهاتف ومسح QR وCode 128 وEAN وUPC وITF وData Matrix، مع سجل محلي للنتائج ووضع ليلي.

## وظائف سابقة

- اسم المنتج والسعر والعملة ومكان وحجم بيانات المنتج.
- معايرة الطباعة: الهوامش، المسافة، ومقياس الطباعة.
- سجل آخر الباركودات مع البحث والتعديل وإعادة الطباعة والحذف.

## التشغيل والتطوير

```bash
npm install
npm run dev
```

## إنشاء نسخة Windows

```bash
npm run dist
```

ينتج الأمر مثبت NSIS ونسخة محمولة داخل `release`. التطبيق مخصص لـ Windows 10 وWindows 11 بنظام x64.
