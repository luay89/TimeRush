# Barcode Studio Android 0.4

يدعم هذا الإصدار طابعة **Xprinter XP-365B** عبر Bluetooth Classic SPP وأوامر ESC/POS.

## المميزات

- اكتشاف الطابعات المقترنة من الهاتف.
- اختيار XP-365B من قائمة الطابعات.
- الاتصال بالطابعة عبر RFCOMM/SPP.
- إرسال باركود Code 128 مباشرة إلى الطابعة.
- طباعة اسم المنتج أعلى الباركود.
- مسح QR والباركود بالكاميرا.
- سجل محلي للنتائج والوضع الليلي.

## قبل الاستخدام

1. شغّل XP-365B.
2. افتح إعدادات Bluetooth في الهاتف وأقرن الطابعة، وغالبًا يظهر اسمها `XP-365B`.
3. افتح التطبيق واضغط **تحديث الطابعات**.
4. اختر الطابعة، ثم أدخل أو امسح الباركود واضغط **طباعة مباشرة**.

## إخراج APK

هذه الميزة تحتاج Development Build لأنها تستخدم Bluetooth Classic Native Module، ولا تعمل عبر Expo Go العادي.

```bash
npm install
npx expo-doctor
npm install -g eas-cli
eas login
eas build --platform android --profile preview
```

ينتج الأمر ملف APK قابلًا للتثبيت على Android. يجب اختبار الطباعة على XP-365B فعلية بعد تثبيت APK، لأن هذا الاتصال لا يمكن محاكاته من بيئة التطوير الحالية.
